# 회원관리 PRD

## 목표
이메일과 비밀번호로 가입하고 로그인한 사용자만 마이페이지를 볼 수 있다.
사용자는 스스로 탈퇴할 수 있다.

## 기능 (이것만)
1. 회원가입: 이메일, 비밀번호, 닉네임 입력. 성공하면 바로 로그인 상태로 메인으로 이동.
2. 로그인: 이메일, 비밀번호. 실패하면 "이메일 또는 비밀번호가 틀렸습니다" 표시.
3. 로그아웃: 헤더의 로그아웃 버튼.
4. 마이페이지(/mypage): 로그인한 사람만. 이메일, 닉네임 표시. 닉네임 수정 가능.
5. 탈퇴: 마이페이지의 "회원 탈퇴" 버튼. 확인 창 한 번. 탈퇴하면 계정과 프로필이 삭제되고 메인으로 이동.

## 만들지 않는 것
소셜 로그인, 비밀번호 찾기, 이메일 인증, 관리자 화면, 프로필 사진, 상품/예약 관련 기능.
이 목록에 있는 것은 제안하지도 않는다.

## 화면
- /signup 회원가입
- /login 로그인
- /mypage 마이페이지 (로그인 필요)
- 헤더: 로그인 전에는 "로그인 / 회원가입", 로그인 후에는 "닉네임님 / 마이페이지 / 로그아웃"

## 기술
- Next.js App Router
- @supabase/ssr (서버와 클라이언트 양쪽에서 세션 유지)
- 데이터베이스 작업은 수파베이스 MCP로 직접 실행
- 비밀 키(secret key)는 쓰지 않는다. 공개 키(publishable key)만 쓴다.
